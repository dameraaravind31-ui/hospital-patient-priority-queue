Binary Max-Heap Internal Data Structure

0 Nodes
Algorithmic Invariant: The waiting queue is maintained using a Binary Max-Heap. Each node at index i satisfies precedence(heap[i]) ≥ precedence(heap[leftChild]) and precedence(heap[i]) ≥ precedence(heap[rightChild]). Higher emergency priority floats to the root (index 0). In case of identical priorities, earlier arrival time takes precedence. This guarantees O(1) immediate identification of the next patient and O(log n) additions and extractions.
